# mods/

Mods for the base game.

- **ContentDB mods:** one folder per mod, copied in with its original license file. Mods written for other Luanti games often need small tweaks (usually block and item names) to work with Mineclonia. See `../docs/porting-mods.md`.
- **Our own mods:** these live inside the game, in `../games/cindrixcraft/mods/CINDRIX/`, and use a `cindrix_` prefix on the folder name, for example `cindrix_core`, so they're easy to tell apart. This top-level folder is for mods taken from ContentDB.

Record every third-party mod in `../CREDITS.md`.
