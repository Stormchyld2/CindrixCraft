# mods/

Mods for the base game.

- **ContentDB mods:** one folder per mod, copied in with its original license file. Mods written for other Luanti games often need small tweaks (usually block and item names) to work with VoxeLibre or Mineclonia.
- **Our own mods:** use a `cindrix_` prefix on the folder name, for example `cindrix_core`, so they're easy to tell apart.

Record every third-party mod in `../CREDITS.md`.
