# games/

`cindrixcraft/` is the CindrixCraft game: a modified copy of Mineclonia 0.124.1 with our title, logo and own mods. See `cindrixcraft/NOTICE.md` for exactly what changed and the licenses.

- Needs Luanti 5.10 or later (the CindrixCraft engine in `../engine/` is based on 5.17.0).
- To use it, copy the `cindrixcraft` folder into the `games` folder of the engine.
- Our own mods live in `cindrixcraft/mods/CINDRIX/`. Mods from ContentDB go in the top-level `../mods/` folder (or a world's `mods/` folder).
- To update Mineclonia later, compare a new release against the 0.124.1 files and reapply our changes listed in `NOTICE.md`.
